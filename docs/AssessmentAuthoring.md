# Assessment authoring workflow

1. Identify the required game event or state in the assessment brief.
2. Locate its scene object, UI control, Prefab, or published parameter using [Project Navigation](ProjectNavigation.md).
3. Create and test the FMOD event in your own FMOD project.
4. Build banks and assign the event or parameter with the official FMOD Unity component.
5. Test normal, boundary, and failure states in Play Mode.
6. Record what you changed and why it supports your creative intention.

The framework supplies state and authoring opportunities; it must not decide the assessed sound design for you. Leave intentional blank event assignments blank until you author them.
