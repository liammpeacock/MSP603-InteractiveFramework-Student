# MSP603 student documentation index

Each item below is an independently linkable or VLE-embeddable topic. These documents are safe for the student distribution; lecturer reference events, audio assets, assignments, and solution notes are not included.

Begin with the [Student Guide](StudentGuide.md). These GitHub pages are living documentation; documentation inside a downloaded release ZIP is the frozen snapshot supplied with that package. Canvas/VLE should link to these pages for current guidance and separately to the approved release asset for the project download.

> **Want to see the game before setting up the project?** [Play MSP603 Tower Defence in your browser](https://bimmmcrliampeacock.itch.io/msp603-tower-defence). No installation is required. Use it to learn the game and its states; use the approved Unity/FMOD project for your own implementation and assessment work.
