# MSP603 student documentation index

Each item below is an independently linkable or VLE-embeddable topic. These documents are safe for the student distribution; lecturer reference events, audio assets, assignments, and solution notes are not included.

These GitHub pages are living documentation. The documentation inside a downloaded release ZIP is the snapshot supplied with that package; use these pages for current guidance and VLE links.

| VLE topic | Resource | Use it when |
| --- | --- | --- |
| Getting started | [Getting Started](GettingStarted.md) | You have downloaded the approved project. |
| Required software | [Required Software](RequiredSoftware.md) | You need to install or check Unity/FMOD versions. |
| Unity setup | [Getting Started](GettingStarted.md#open-the-unity-project) | You are opening the project for the first time. |
| FMOD setup | [FMOD Setup](FMODSetup.md) | You are connecting your own FMOD Studio project and banks. |
| Project navigation | [Project Navigation](ProjectNavigation.md) | You need to locate scenes, controls, prefabs, or hooks. |
| FMOD component workflow | [FMOD Component Workflow](FMODComponentWorkflow.md) | You are adding/configuring official FMOD Unity components. |
| Authoring opportunities | [FMOD Authoring Reference](FMODAuthoringReference.md) | You need the supported parameter and hook catalogue. |
| Assessment workflow | [Assessment Authoring](AssessmentAuthoring.md) | You are planning and testing your implementation. |
| Play guide | [Vertical Slice Play Guide](VerticalSlicePlayGuide.md) | You need to exercise the game states. |
| Recovery and support | [Troubleshooting and Support](Troubleshooting.md) | FMOD/Unity transfer or runtime setup has failed. |

The approved download is the only project to use. Do not clone a lecturer-controlled source repository or use a GitHub source archive as an assessment project.
