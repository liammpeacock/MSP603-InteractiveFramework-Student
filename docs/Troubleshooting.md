# Troubleshooting and support

## FMOD transfer or reinstall recovery

FMOD-for-Unity integrations can occasionally become invalid after a project is downloaded, copied, zipped, unzipped, or transferred.

1. Close Unity and FMOD Studio.
2. Remove the damaged FMOD-for-Unity integration from the local project copy.
3. Reinstall **FMOD for Unity `2.03.14`**.
4. Reopen the project in Unity `6000.0.78f1`.
5. In **FMOD > Edit Settings**, reconnect your own FMOD Studio project or bank directory.
6. Rebuild your banks and refresh them in Unity.

This recovery procedure does not provide, copy, or require lecturer reference banks or event assignments.

## Reporting a problem

Use **Report a Bug** in the Main Menu or pause menu. If the framework cannot open, use the MSP603 bug-report form provided in the VLE. Include the scene, action, expected result, actual result, reproducible steps, Unity version, and FMOD version. Exclude passwords, credentials, and unnecessary personal data.
