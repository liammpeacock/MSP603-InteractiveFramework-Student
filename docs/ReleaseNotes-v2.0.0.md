# MSP603 Student v2.0.0 — 26 November 2026

An optional upgrade. Existing students may retain the version specified in their assessment brief/VLE; original v1.1.0 remains available.

## New Features

EnemyCount, RunnerCount, GruntCount and ArmouredCount are Global Continuous/game-controlled, each independently 0–60/default 0 with spawn/removal/level/restart/terminal resets. Pause publication/emitter lifecycle, Run In Background/Live Update and a 15% effective tower-range increase are retained.

## Bug Fixes

Input System UI and assembly configuration; Lives is published before LifeLost starts and resets to 20 on level/restart. SFX routing respects the Gameplay pause and volume controls. Lives ordering does not reset Sequential Global Scope playlist history.

## Audio-free authoring

All 24 event identities, parameters, mixer routing, Unity assignments and six matching rebuilt banks are supplied. There is **no authored audio in the FMOD source or banks**. Music, effects, footsteps and pause ambience are silent until you author and build your own audio. Preserve supplied identities/structures and use your own licensed audio; no private reference banks are needed.

## Compatibility and installation

Unity 6000.0.78f1, included FMOD for Unity/native 2.03.13, Studio 2.03.13 authoring baseline. The empty banks were generated by existing Studio 2.03.14 and validated with 2.03.13; no integration upgrade is required. Extract into a new local writable folder, keep Unity and Audio adjacent, and open the supplied Student.fspro. See [setup](FMODSetupGuide.md), [software](RequiredSoftware.md) and [migration/backups](StudentMigration.md).

## Verification and limitations

Real extracted-package checks pass 22 EditMode and 55 PlayMode tests with no skips/failures, native 2.03.13 event/parameter/bank checks, all payload hashes and audio-free content checks. Canonical audible acceptance was maintainer-confirmed; the Student package is intentionally silent. New tests cover macOS Apple silicon; fresh Windows runtime acceptance was not performed. Existing browser reference is unchanged.
