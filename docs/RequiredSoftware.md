# Required software

Install this validated set before opening the project:

| Software | Required version |
| --- | --- |
| Unity Editor | `6000.0.78f1` |
| FMOD Studio | `2.03.14` |
| FMOD for Unity | `2.03.14` (already integrated in the supplied project) |

The student project is a single platform-neutral Unity authoring package validated for Windows/Intel x64 and macOS Apple silicon. It is not a prebuilt executable. Use the operating system version of Unity and FMOD Studio supplied or approved by your institution.
