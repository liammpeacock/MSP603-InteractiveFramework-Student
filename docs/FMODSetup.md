# FMOD setup

1. Create your own FMOD Studio project in a location you control.
2. Create the events and parameters required by the assessment brief.
3. Assign events to banks and build those banks for your current platform.
4. In Unity, choose **FMOD > Edit Settings**.
5. Connect the supplied Unity project to your FMOD Studio project or its built-bank directory.
6. Let Unity refresh the Event Browser, then assign your events on the existing **Student FMOD Authoring** scene objects and prefabs.

Use the exact parameter names and labels in [FMOD Authoring Reference](FMODAuthoringReference.md). Do not copy a lecturer project, reference bank, or another student's event assignments.

If a transfer or reinstall invalidates FMOD, use the recovery steps in [Troubleshooting and Support](Troubleshooting.md#fmod-transfer-or-reinstall-recovery).
