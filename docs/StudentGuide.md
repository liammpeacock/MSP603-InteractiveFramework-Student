# MSP603 Student Guide

This is the student-facing guide for the **MSP603 v1.0.0 Student FMOD** project. It is deliberately separate from the lecturer reference implementation. Empty FMOD event fields and unconfigured bank paths are part of the assessment workflow, not faults.

## Start here

1. Read [Getting Started](GettingStarted.md).
2. Confirm the required software in [Required Software](RequiredSoftware.md).
3. Connect your own FMOD project using [FMOD Setup](FMODSetup.md).
4. Find safe authoring locations with [Project Navigation](ProjectNavigation.md).
5. Follow the module brief and [Assessment Authoring](AssessmentAuthoring.md).

## Help and support

Use [Troubleshooting and Support](Troubleshooting.md) before reporting a problem. Do not include passwords, credentials, or unnecessary personal information in a report.

## Academic integrity

Your FMOD events, sound design, parameter mapping, and creative decisions are your work. AI output and technical examples can be incomplete; verify them and follow the university's current academic-integrity and AI-use policy.
